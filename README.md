## Project Overview
This Power BI dashboard provides insights into sales performance across regions and product categories.

## KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %

## Visualizations
- Monthly Sales Trend (Line Chart)
- Category-wise Sales Distribution (Pie Chart)
- Region-wise Sales Analysis (Bar Chart)
- Interactive Region Slicer

## Tools Used
- Power BI
- DAX
- Data Visualization
- Business Analytics

## Key Insights
- Tracked sales trends over time
- Compared regional performance
- Analyzed category contribution to revenue
- Measured profitability using profit margin
